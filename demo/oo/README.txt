Sample programs for ooRegina
============================

Run any of them with:   rexx 01_classes.rexx

01_classes.rexx          classes, attributes, private and class methods
02_inheritance.rexx      subclasses, abstract methods, polymorphism,
   + shapes.cls          a class library loaded with ::requires
03_collections.rexx      Array, Directory, Queue, Table, Supplier
04_operators.rexx        operator methods: a Fraction class with + - * / = <
05_stems.rexx            stems passed by reference and returned
06_data_structures.rexx  a Stack built on Array, a binary search tree
07_dynamic.rexx          UNKNOWN (a logging proxy), mixins, SEND/SENDWITH
08_inventory.rexx        a small stock-keeping application
09_lisp.rexx             LISP-style lists: an expression evaluator, quicksort
10_python.rexx           Python libraries: statistics, collections, json
11_blocks.rexx           blocks { :x | ... } with select, collect, inject, sortWith
12_extensions.rexx       Bag, Set, SortedCollection, Interval, ::extension, ensure
13_notation.rexx         CREXX/NetRexx notation: obj.m(), .Class(), this, null,
                         USE ARG defaults, is, as, typeof
14_netrexx.rexx          a NetRexx program (options netrexx; also *.nrx files)
15_crexx.rexx            a CREXX program (options levelg): interfaces,
                         factories, match

../oo_demo.rexx          a quick self-test of classic and OO features
